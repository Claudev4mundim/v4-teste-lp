# V4 Teste · LP de teste do V4 Tags

Página para testar as integrações do V4 Tags (GTM, GA4, Meta Pixel, Clarity e
LeadStaker) sem mexer em LP de cliente.

- Endereço: https://v4-teste.v4mundim.com/
- Quatro botões com cara de CTA, para testar o modal do LeadStaker (Modal Popup
  e Ambos), mais menu, formulário e link de rodapé, que não devem virar modal.
- O painel no canto esquerdo mostra quantos botões estão com a classe
  `cta-leadstaker` e se o script do LeadStaker carregou.

As mudanças nas tags são feitas pelo V4 Tags, que grava direto neste
repositório.
